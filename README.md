# BrosContent Website

This is a modern, high-contrast marketing agency website built with React and Vite.

## Setup Instructions

1.  **Install Node.js**: Ensure you have Node.js installed.
2.  **Install Dependencies**:
    ```bash
    npm install
    ```
3.  **Run Development Server**:
    ```bash
    npm run dev
    ```
4.  **Build for Production**:
    ```bash
    npm run build
    ```

## Project Structure

- `src/components`: Reusable UI components (Navbar, Hero, Services, Footer).
- `src/index.css`: Global styles and strict brand variables.
- `src/App.jsx`: Main page assembly.

## Design System

- **Colors**: Yellow (#F5B301), Black (#0B0B0B), White (#FFFFFF), Gray (#2E2E2E).
- **Typography**: Inter (Google Fonts).
